# Code of Conduct

## Our commitment

We want LPI for Linux to be a welcoming, respectful and constructive open-source project.

## Expected behavior

- Be respectful and professional.
- Welcome different viewpoints and experience levels.
- Focus on technical facts and constructive feedback.
- Report security issues privately.
- Avoid harassment, insults, discrimination and personal attacks.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, discrimination, deliberate disruption,
publishing private information, and any other conduct that makes participation unsafe or hostile.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, or restrict participation
when necessary to keep the project constructive and safe.

For security vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
